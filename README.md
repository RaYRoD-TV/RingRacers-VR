# Ring Racers VR

Dr. Robotnik's Ring Racers in VR. Native OpenXR, four view modes, motion controllers & comfort options.

Install it through the [Multiverse VR Hub](https://github.com/RaYRoD-TV/MVRH). One exe, it fetches the official Ring Racers release & patches it.
